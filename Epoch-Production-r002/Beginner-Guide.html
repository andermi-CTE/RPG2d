Play, change one thing, test

Start · Play Epoch · Beginner guide

Your files

  • game/pack.js: your title, town layout and guide dialogue.
  • game/epoch-rpg.js: the RPG adapter, annotated rules, original placeholder drawing, encounters and battle commands.
  • game/index.html: bundled class engine. Keep this file intact.

First code change

  1. Make a backup of the folder.
  2. Open game/pack.js in your editor.
  3. Ctrl+F for Welcome to Epoch.
  4. Replace only the words inside that quoted sentence. Preserve the quotes and comma.
  5. Save. Refresh the game. Walk to Town hall and press E to verify your exact sentence.
  6. Record what changed and the test result in your project log.

Next small change

In game/epoch-rpg.js, search for name: 'Moss Imp'. Change only the enemy name, save, refresh, and walk until the first encounter. Later, change one number in RULES and compare the outcome. Existing saved hero stats do not automatically change when starting values change.

Controls and rules

WASD/arrows walk; E interacts. In battle: 1 Attack, 2 Herb, 3 Run. The sentinel prevents running. Healing uses your turn and the enemy responds. An empty herb supply does not spend a turn. Combat pauses walking. Experience thresholds are cumulative: level 2 at 10 XP, level 3 at 20 XP. Leveling restores HP. Encounters occur every 14 successful outdoor steps for predictable classroom demonstrations.

The inn heals for 3 gold. The shop sells an herb for 3 gold. Defeat: press Enter to return home, fully healed, losing half your gold. R resets the outdoor position, not stats. Escape works outside battle. All four town roads currently reach the same countryside entrance.

Saving

Use the town save station to save HP, level, XP, gold, herbs and tower completion in this browser. Map position is not saved. Save again after making progress; there is no automatic save. Storage can be blocked; the game remains playable and reports that saving is unavailable. Clearing browser site data removes the save.

Test checklist

  1. All four roads enter the countryside; Escape returns home.
  2. Move in all four directions; water blocks movement.
  3. Test attack, healing and escape; confirm stats and victory rewards.
  4. Defeat the sentinel and return home; check the completion banner.
  5. Test the inn, shop, defeat recovery, restart and save/reload.
  6. Change the guide greeting and verify it in game.

Custom artwork belongs in a future assets folder; record prompts and sources before integrating it. This version needs no external assets.

Optional shared Overworld integration

This adapter is installed only in this standalone package. Copying pack.js alone supplies the older marker exercise, not the RPG. Shared-world integration requires adapting the scene registration and home hook; it has not been published to the class world.
