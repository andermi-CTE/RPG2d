Epoch project information

Start · Play Epoch · Beginner guide

Owner: Teacher demonstration project.

Direction: Dragon Warrior–style NES top-down RPG. Original graphics, names and rules; no copied game assets.

Starter goal: Explore from town, survive turn-based encounters, defeat the Tower Sentinel, and return home.

Next assignments: name the town; personalize one guide sentence; design a hero sprite; plan town/tower artwork; test one small rule change. Record prompt attempts, saved assets, code changes and expected/actual results just as students do.

Use your existing project log and Week 13 log to record work and evidence.

This package does not mark assignments complete or change grades. The prior r001 starter remains available in Starting Files. Production r002 is a separate demo package; any existing GitHub working copy remains separate.
